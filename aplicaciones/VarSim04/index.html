Mixtura en dos pasos

T, Modelo|T=1

De dos uniformes a un beneficio

Cambia U₁ o U₂, o lanza ambos al azar, y sigue el camino de decisión del cliente. Los parámetros de la mixtura se editan en la pestaña Simulación.

Cómo funciona el algoritmo de mixtura

1 · GENERAR T

Se genera u₁ ~ U(0,1). Si u₁ < Pr(compra), el cliente compra (T=1); si no, T=0 y el beneficio es 0 €.

2 · GENERAR MODELO

Solo si compra: se genera u₂ ~ U(0,1) y se aplica la transformada inversa sobre las probabilidades de los tres modelos para elegir uno.

3 · BENEFICIO

B = 0 si no compra; B = ganancia del modelo si compra. Repetido muchas veces, reproduce exactamente la mixtura.
