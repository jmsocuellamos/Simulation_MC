Cambia de plan o lanza una nueva U, y observa qué retorno produce el algoritmo. Los valores y probabilidades de cada plan se editan en la pestaña Simulación.

Cómo funciona el algoritmo

1 · GENERAR

Se genera u ~ U(0,1). Es lo único que sabe producir un generador de números aleatorios.

2 · BUSCAR EL TRAMO

Se busca el menor índice i tal que u ≤ F(i) = p₁+…+pᵢ, usando las probabilidades acumuladas del plan elegido.

3 · DEVOLVER

Se devuelve el retorno R = vᵢ de ese tramo. Repetido muchas veces, reproduce exactamente las probabilidades del plan.

Simulación Monte Carlo frente al valor teórico

Retorno teórico = Σ pᵢ·vᵢ. Riesgo teórico = raíz de Σ pᵢ·(vᵢ−media)². Pr(pérdida) = Pr(R < I₀).
